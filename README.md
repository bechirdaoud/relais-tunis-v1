# Relais Tunis v1

Static v1 website for Relais Tunis.

## Update WhatsApp number

Edit `script.js` and replace:

```js
const WHATSAPP_NUMBER = '216XXXXXXXX';
```

with the real number in international format, for example:

```js
const WHATSAPP_NUMBER = '21612345678';
```

## GitHub Pages

The site is designed to be published from the root of the `main` branch.
